# ADR-016: PostgreSQL transaction and RLS context

**Status:** Accepted  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Every tenant-aware repository operation runs in an explicit transaction that sets tenant, workspace, user, membership, service/agent principal, and policy version with SET LOCAL. Application roles cannot use BYPASSRLS; FORCE ROW LEVEL SECURITY is enabled for tenant tables.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
