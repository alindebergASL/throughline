# ADR-017: Source normalization, chunking, offsets, and citation verification

**Status:** Accepted  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Persist normalized SourceChunks with stable offsets and hashes. Model-emitted citations are candidates only. Trusted server code validates source ownership, access, offsets, hash, and exact excerpt reconstruction before a Claim can enter review.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
