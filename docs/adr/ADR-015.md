# ADR-015: Auth provider and local-development identity strategy

**Status:** Accepted
**Date:** 2026-06-24
**Context:** Throughline Phase 0/1

## Decision

Use a provider-neutral internal identity model. Evaluate WorkOS AuthKit for production B2B auth; local development uses a deterministic dev identity adapter. No domain table stores provider-specific identity as its primary key.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
