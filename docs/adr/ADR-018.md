# ADR-018: Access-class lattice and redaction/republication

**Status:** Accepted  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Use public < workspace < restricted < confidential. Derived objects inherit the most restrictive effective input class. Downgrading requires a separate, authorized redaction-and-republication ChangeSet that creates a new artifact.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
