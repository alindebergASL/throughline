# ADR-019: Domain Command Bus and optimistic concurrency

**Status:** Accepted  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Every human and agent mutation enters through typed AuthorizedDomainCommands. Commands are reauthorized at execution, require entity/revision preconditions, are idempotent, emit outbox events with aggregate versions, and never allow route handlers or adapters to write domain tables directly.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
