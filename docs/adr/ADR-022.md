# ADR-022: Account Research MCP transport and authorization

**Status:** Proposed  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Implement a read-only remote MCP adapter behind the Capability Broker. Use the stable 2025-11-25 MCP authorization baseline for protected HTTP servers, HTTPS, OAuth resource metadata, PKCE S256 where applicable, audience-bound tokens, least privilege, server identity allowlisting, and no token passthrough.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
