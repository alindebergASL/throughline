# ADR-021: Initial model provider and evaluation baseline

**Status:** Proposed  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

Select the first extraction model only after running the same transcript fixtures against at least two model candidates. Choose by provenance accuracy, consequential-item recall, schema adherence, latency, and cost—not generic benchmark quality.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
