# ADR-020: Agent workflow durability, retries, atomic groups, and compensation

**Status:** Accepted  
**Date:** 2026-06-24  
**Context:** Throughline Phase 0/1

## Decision

AgentRun and ChangeSet are durable workflow records. Each attempt has a versioned ExecutionReceipt. Atomic groups succeed or compensate together; unrelated operations may complete independently. Provider acceptance and state verification are separate states.

## Consequences

- This ADR is binding for Phase 0/1 once Accepted.
- Deviations require a superseding ADR.
- Implementation must include tests that demonstrate the decision.

## Deferred

Details not required for the corresponding Phase 0 gate remain implementation choices.
