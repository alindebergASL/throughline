# Throughline Phase 0 Demonstration Script

1. Start from an empty local environment and run migrations.
2. Sign in as the Workspace Owner; create Tenant, Workspace, and root Space.
3. Invite User B and create a restricted child Space visible only to the owner.
4. Manually create a fictional Organization, Initiative, and Engagement.
5. Paste `normal_discovery.txt`; inspect SourceArtifact, chunks, hashes, and access class.
6. Run deterministic fixture extraction first, then model extraction behind the same schema.
7. Show the ChangeSet groups: Needs Attention, Ready to Accept, Needs Another Approver.
8. Open three items and prove the excerpt is reconstructed from verified offsets.
9. Accept, edit, reject, and submit; show Domain Commands and ExecutionReceipts.
10. Generate cited Organization and Initiative summaries from AcceptedFacts.
11. Repeat with `conflict_workshop.txt`; prove conflicts remain and scheduling is not executed.
12. Repeat with `adversarial_injection.txt`; prove the injected text cannot access tools or downgrade impact.
13. Add a restricted source in the child Space; sign in as User B and prove no text, title, count, citation, summary, Pulse, or semantic influence.
14. Tighten a permission and supersede a fact; prove DerivedViews regenerate.
15. Configure the mock AccountIntelligenceProvider; import research as Claims only.
16. Swap to the Account Research MCP adapter; pass the same contract.
17. Disable all adapters and prove manual Throughline remains functional.
18. Display audit, run trace, cost budget, policy version, and security test results.

## Pass condition

The demo passes only when the trust, security, and adoption gates in the Build Specification are all green.
